# Annex B: AI Image Generation Prompts
## Complete Prompt Library for Neural-Themed Visual Assets

### Design System Overview

This document contains the complete collection of prompts used to generate the 27 neural-themed images for the ENGRAM website. These prompts can be used with ImageZ, Midjourney, Stable Diffusion, or any AI image generation tool.

**Visual Theme**: Scientific elegance meets neural complexity  
**Color Palette**: Deep space dark (#0a0a0f) with electric cyan (#00d4ff), magenta (#ff006e), violet (#8338ec), and gold accents (#ffd700)  
**Style**: Minimalist scientific aesthetic with bioluminescent accents, clean typography, sophisticated data visualizations

**How to Use This Guide:**
1. Select the appropriate prompt category for your needs
2. Copy the prompt and adjust parameters if needed
3. Generate images at 1200x1200px or 16:9 aspect ratio
4. Apply CSS overlays (70-85% opacity) for web integration

## GENERATION NOTES

### Technical Specifications
- **Resolution**: All prompts optimized for 8K generation
- **Aspect Ratios**: Mix of 16:9 (desktop), 21:9 (ultrawide/headers), 1:1 (icons), 9:16 (mobile)
- **Color Consistency**: Maintain cyan (#00d4ff), magenta (#ff006e), violet (#8338ec), gold (#ffd700) palette
- **Background**: Predominantly deep black (#0a0a0f) or dark navy
- **Style**: Consistent scientific elegance across all assets

### Usage Priority
1. **Hero backgrounds** (1.1, 1.2, 1.3) - Primary visual impact
2. **Section dividers** (3.1, 3.2) - Consistent visual rhythm
3. **Card backgrounds** (5.1, 5.2) - UI component polish
4. **Icons** (6.x series) - Interface elements
5. **Footer** (4.1, 4.2) - Professional closure
6. **Special effects** (8.x series) - Interactive enhancements

### Recommended Workflow
1. Generate hero images first (highest impact)
2. Generate section dividers for consistent visual language
3. Generate card backgrounds for component library
4. Generate icons as needed for specific sections
5. Generate footer background last
